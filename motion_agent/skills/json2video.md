# JSON2Video rendering skill

Create Movie JSON with a resolution and a scenes array. Supported visual element types include text, image, video, html, component, audiogram; audio types include audio, voice and subtitles. Every element belongs inside a scene's elements array or at movie level. Use seconds for timing. Text elements use text, style and settings; use CSS property names such as font-family, font-size, font-weight, color, background-color and text-align. Elements support x/y/width/height, position, start, duration, fade-in, fade-out, z-index and keyframes. Scene transitions use type xfade, a supported style such as fade, dissolve, wipeleft, slideleft or circleopen, and a duration. Do not invent URLs: image/video/audio src values must be user-supplied or known public HTTPS assets. Validate the movie before saving. Submit a render only when the user explicitly requests a final render; rendering consumes the connected JSON2Video account quota. Poll status until done/error/timeout and report the returned MP4 URL only when present.
