# Voiceover and narration

Voiceover is optional and must serve the brief. Use JSON2Video's native `voice` element for TTS narration embedded in the final motion video. Choose Azure or ElevenLabs only when the selected voice ID/name is verified and supports the requested language. If no voice is specified, ask only when the choice materially affects the deliverable; otherwise use a safe provider default and disclose the choice. Write concise spoken language, not dense on-screen copy. Structure narration with pauses and match each segment to scene timing. Do not synthesize an unauthorized imitation of a real person's voice or imply endorsement. When subtitles are requested, add a subtitle element synchronized with the voice track. Never add narration by default to a purely visual logo animation unless it improves the brief.


For Amharic (Ethiopia), JSON2Video's Azure catalogue lists `am-ET-MekdesNeural` and `am-ET-AmehaNeural`. Use these exact identifiers when Amharic narration is requested, and let the user choose a voice if gender/tone preference is unclear.
