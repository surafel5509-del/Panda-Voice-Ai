# Cinematic visual direction

Design cinematic title sequences, product promos and explainers with intentional contrast, depth cues, controlled highlights, negative space and camera-like movement. Use subtle fades, wipes, slides and scale/position keyframes only when they reinforce the story. Do not claim true 3D geometry when the available renderer only supports composited 2D layers. For a true 3D request, produce a shot list and asset brief for a dedicated 3D engine.
